This is a research work to use Transformer model detect fall and ADL

Dataset used to train the model are Le2i and CAUCAFall


Le2i Dataset
Charfi, I., Mitran, J., Dubois, J., Atri, M., & Tourki, R. (2013). Optimised spatio-temporal descriptors for real-time fall detection: Comparison of SVM and Adaboost based classification. Journal of Electronic Imaging, 22(4), 1–17.

CAUCAFall Dataset
Eraso Guerrero, J. C., Muñoz España, E., Muñoz Añasco, M., & Pinto Lopera, J. E. (2022). Dataset for human fall recognition in an uncontrolled environment (CAUCAFall). Data in Brief, 45, 108610. https://doi.org/10.1016/j.dib.2022.108610
